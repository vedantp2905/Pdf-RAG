# AI-Powered Customer Service Chatbot

A sophisticated chatbot application built with Streamlit and CrewAI that provides intelligent customer service responses using either OpenAI's GPT-4 or Google Gemini models.

## Features

### 1. Dual LLM Support
- Seamless integration with both OpenAI (GPT-4) and Google Gemini models
- API key verification system for secure model access

### 2. Multi-Agent System
- **Customer Service Specialist Agent**: Primary response generator with RAG capabilities
- **Brand Consistency Agent**: Quality assurance for maintaining brand voice
- Option to switch between single agent or crew mode for different complexity levels

### 3. RAG (Retrieval Augmented Generation)
- Document search tool for accurate information retrieval
- Configurable embedding models for different LLM providers

### 4. Interactive Chat Interface
- Persistent chat history across sessions
- Real-time message updates
- Markdown support for formatted responses
